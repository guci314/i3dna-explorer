# __微任务执行程序 · 使用说明（通用引擎版）

功能：解析微任务 → 提取参数 → 生成成果 → 按目录名称自动匹配存储。
（说明.txt 第 3 条的功能半句由此承接；其架构半句——"引擎存进包内、从中选定"——已裁定无效：客户在 IT 架构轴是 chooser 不是 author，引擎架构见下。）

**分层（2026-08-06 裁决）**：引擎本体是 **MOF M2 层工具链**，住 `report_generate/i3dna-engine/i3dna_engine.py`，不随应用包分发（引擎入包＝把 Python 解释器塞进 ERP 源码）；本目录的 `__微任务执行程序.py` 只是 **M0 层调用垫片**——定位工具链、转发参数，换机用环境变量 `I3DNA_ENGINE` 重定向。旧做法（包内全量副本＋手工 cp 同步）作废。

## 四个命令

```bash
# 列出包内全部微任务（三代格式通吃）
python3 __微任务执行程序.py list <包根目录>

# 预检：树根自校准 + 输入齐备性 + 产物槽位（缺输入即拒绝点火）
python3 __微任务执行程序.py preflight <微任务目录>

# 真执行：调大模型生成产物 → 写产物槽 → 机器代笔登记目标索引 → 写 __结果.json
python3 __微任务执行程序.py run <微任务目录> [--platform 技术栈] [--sandbox 目录] [--engine "命令"] [--output 名称@锚目录]

# 回填：不调模型，对既有产物补记 __结果.json（状态=事后追认，缺失如实记录）
python3 __微任务执行程序.py backfill <微任务目录> [--note "备注"]
```

## 引擎（合规刀口在模型国籍，不在 harness）

默认 **OMP + 国产模型**：`omp -p --no-session --thinking high @{prompt_file}`（提示词经临时文件传入，模型由 OMP 配置决定，当前 GLM 5.3；思考档 8-19 裁定默认 high——max 档沉思可整池烧穿 128K 输出+思考共池）。可用环境变量 `I3DNA_LLM_CMD` 或 `--engine` 换任意 CLI：命令串含 `{prompt_file}` 时替换为提示词文件路径，不含时提示词走 stdin；命令串中的 `~` 与 `$VAR` 会展开。

常用合规组合（按企业政策选，本机实测）：

| 政策 | 引擎串 |
|---|---|
| 全国产（默认） | `omp -p --no-session --thinking high @{prompt_file}`（OMP 当前配 GLM 5.3） |
| 允许 Claude Code 壳、模型须国产（GLM） | `~/start-claude-glm.sh -p` |
| 允许 Claude Code 壳、模型须国产（DeepSeek） | `~/start-claude-deepseek.sh -p` |
| 无限制 | `claude -p --permission-mode acceptEdits` |

要点：**合规刀口在模型国籍不在 harness**——启动脚本负责把国产端点＋Keychain 里的 key 注入后透传参数给 claude，单设 `CLAUDE_CONFIG_DIR` 会报"Not logged in"（key 不在配置目录里）。write 模式（默认）要求引擎 agent 有文件写入权：OMP 无头自带；启动脚本内置跳过确认；裸 `claude -p` 需加 `--permission-mode acceptEdits`，否则改用 `--io stdout`。启动脚本有几行横幅打在 stdout，write 模式无害（产物不走 stdout）；stdout 模式有前缀清洗兜底。

## Agent API（`i3dna_api.py`，不碰界面的交互面）

不擅长操作界面的 agent（LLM/脚本/CI）从这里与目录体系交互：

- **读桥**（本进程直算，一律 JSON 到 stdout，拒绝也机读 `{拒绝:…}`+退出码 2）：
  `tree`（域/类·方法·关系边/场所拓扑）、`tasks`（任务清单·案卷们·执行者·色彩·校验门）、
  `task`（弧解析预检：在场/可缺/回收/产物目标）、`account`（账本**盘直读**——
  不经任务定义，定义侧损坏不吞已点火的账，坏账以「坏账」行露出）、
  `lint`（报告 JSON，退出码随错误）、`coverage`（MBT 变迁/边覆盖，有缺口退 1）。
  `--task` 一律树内相对路径，越界/根不存在＝{拒绝}+退出码 2。
- **写桥**（subprocess 直通引擎对应动词，引擎仍是唯一写路径，stdout/退出码原样）：
  `fire`→`run`、`settle`→`backfill`（办结：校验门+回收弧+事后追认）、
  `advance`→`converge`（推进）、`login`（登录入账）。

```bash
python3 i3dna_api.py tasks md-devloop-m1
python3 i3dna_api.py task md-devloop-m1 --task 域/治理域/类/女娲/方法/立场所 --case 广州开发一部
python3 i3dna_api.py fire md-devloop-m1 --task <任务相对路径> --case <案卷> --executor 实例/人员/<姓名>
```

## IO 两模式（`--io`，默认 write）

- **write（默认）**：引擎 agent 用自己的文件工具**直接把产物写到指定绝对路径**，本程序只做后置条件验收（存在/非空/确被改动，验收不过即报错）。产物不经聊天回复，从机制上免疫"解释前缀污染"和多产物切分问题。
- **stdout**：产物内容回传、本程序落盘（写临时→rename），供裸 LLM API 类引擎使用；带前缀清洗兜底（开头闲话自动切到首个标题/围栏/产物标记）。

## 通用性

- **三代格式适配**：①参数表族（8.5，`__*大模型智能体*版本.xlsx`）全自动；②任务定义族（7.26，`__*任务定义*.md` 作任务指令）与③纯索引族（7.17 布局）需 `--output 名称@锚目录` 显式声明产物。
- **输入/产物判定**：优先认类型串末段的角色标记（`_输入参数文件】`/`_成果模型文件】`/`_生成函数文件】`），无标记退回"目录名称自动匹配"（目标轴段推断）。
- **树根自校准**：用配方里的锚路径对祖先目录打分自动定树根（`__创建窗口`/`___勘察系统-01`/`_简化版` 布局通吃），`--root` 可强制。
- **两级寻址展开**：输入若是索引文件，其外联行自动展开为真输入（目录寻册、册内归查询参数）。
- **多产物**：声明多个产物时要求模型按 `<<<I3DNA-产物:文件名>>>` 分隔，引擎按名切分落盘；缺文件拒绝落盘。

## 纪律

- 预检不过不点火（无 oracle 不得 PASS）；产物写临时→rename（原子）；索引只许机器代笔追加。
- `__结果.json` 与 i3dna-lint 对账兼容（名称=相对树根路径＋字节＋sha256）；
  目录输入弧记**盘点单**（名称＋目录:真＋清单{文件:sha}，收盘盘点，
  `__` 前缀不入——账不进账；目录已变=专用催火理由，§8.12）。
- `--sandbox` 模式 canonical 树一字不动，产物/索引副本/结果.json 全进沙盒镜像，供对拍。
